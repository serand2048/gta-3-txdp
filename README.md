# TXDP для GTA III 1.0 (PC)

ASI-плагин, переносящий секцию `txdp` из GTA San Andreas ([описание на вики](https://gtamods.com/wiki/TXDP)): если текстуры нет в TXD модели, она берётся из родительского TXD.

Проверен только на **GTA III 1.0 (PC)**. На других версиях (1.1, Steam) не заработает: адреса функций другие.

## Установка

1. Нужен ASI Loader (например, Ultimate ASI Loader).
2. Положите `txdp.III.asi` в папку `scripts` игры (или в корень, рядом с `gta3.exe`).
3. Добавьте секцию `txdp` в любой `.ide` (см. ниже).
4. При первом запуске рядом с плагином создастся `txdp.III.ini` (см. «Настройки и лог»).

## IDE

```
txdp
child_txd, parent_txd
end
```

Секцию можно класть в любой `.ide`, в том числе через modloader. Если текстуры нет в `child_txd`, она ищется в `parent_txd`, затем выше по цепочке (до 8 уровней).

Родитель должен быть одним из:

- файл в `gta3.img`;
- файл через modloader (имя файла должно совпадать с именем TXD в IDE: `parent_txd.txd`);
- `generic.txd`.

TXD должны быть в формате GTA III (платформа D3D8). Формат Windows/D3D9 (как в SA) игра не читает.

## Что делает плагин

- Читает секцию `txdp` через перехват `CFileLoader::LoadLine`.
- При сборке DFF (вызов `0x5AAE1B`, чтение текстуры материала) ищет промахнувшуюся текстуру у родителей.
- Стриминг: родитель запрашивается вместе с ребёнком (флаг DONT_REMOVE), а загрузка ребёнка откладывается, пока родитель не загружен (как в SA).
- Защита от зависания. Если TXD не читается (например, сохранён в формате Windows/D3D9, а не GTA III), игра сама перезапрашивает его бесконечно, и загрузка зависает без краша. Плагин подставляет такому TXD пустой словарь (его текстур не будет, но игра работает) и пишет причину в лог:
    - до чтения проверяется платформа первой текстуры (D3D9/Xbox/PS2 = неверный формат), так что RenderWare такой файл не видит;
    - покрыты оба пути загрузки игры: `LoadTxd` (файлы до ~400 КБ) и `StartLoadTxd`/`FinishLoadTxd` (крупнее);
    - любой TXD, который 3 раза не загрузился или 20 раз подряд не прошёл `ConvertBufferToObject`, тоже получает пустой словарь.
## Сборка

1. Установите plugin-sdk, задайте переменную окружения `PLUGIN_SDK_DIR` (путь к папке plugin-sdk) и соберите его библиотеки (`Plugin_III.lib` появится в `output\lib`).
2. Откройте `txdp.slnx` в Visual Studio (набор инструментов v145; на VS2022 выберите v143), конфигурация `Release GTA3`, платформа Win32.
3. Код плагина лежит в `source\Main.cpp`. Макросы (`GTA3`, `PLUGIN_SGV_10EN`, `RW` и др.) уже заданы в `txdp.vcxproj`.
4. Результат: `bin\GTA3\Release\txdp.III.asi`. Если задана переменная окружения `GTA_III_DIR`, после сборки файл копируется в `scripts` игры (запущенная `gta3.exe` при этом закрывается).

## Настройки и лог

Файлы настроек и лога называются по имени плагина и лежат рядом с ним: у `txdp.III.asi` это `txdp.III.ini` и `txdp.III.log`.

Если ini нет, плагин создаёт его сам при первом запуске игры:

```
[Main]
Log=0
```

`Log=1` включает лог (файл `txdp.III.log`, перезаписывается при каждом запуске). `Log=0` (по умолчанию): плагин ничего не пишет на диск.

Полезные строки лога:

- `txdp: A (n) -> B (m)` - разобранные пары (кроме `-> generic`)
- `request txd 'A': parent 'B'` - запрос родителя
- `defer txd 'A': waiting for parent 'B'` - ребёнок ждёт родителя
- `texture 'x' (txd 'A'): found in parent 'B'` - текстура найдена у родителя
- `... parent 'B' is loaded but has NO such texture` - в родителе нет текстуры с таким именем (дальше список его текстур)
- `FAILED (...) to load TXD` - TXD не читается
- `TXD ... has the wrong format` - неверная платформа, пересохраните TXD в формате GTA III
